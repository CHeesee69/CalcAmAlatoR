# CalcAmAlatoR
The CalcAmAlatoR (kal-kuh-ma-ley-ter) is an advanced terminal calculator written in Python. Currently, it has four different operations:

- Basic Arithmetic
- Geometric Shapes
- Triganamirty
- Basic Algebra

## Dependencies
Python (preferably the latest; You can get it here)
sympy
Use
Just download the zip and run the "Main_v1.0.py" file using Python
